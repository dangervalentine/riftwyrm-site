# Implementation Plan: Riftwyrm Marketing Site

**Branch**: `main` (Principle II; feature identity is `specs/001-marketing-site`) | **Date**: 2026-11-02 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-marketing-site/spec.md`

## Summary

Turn the one-card landing page into a small marketing site for Riftwyrm. It is built from the game's
own material:

- real seeded store screenshots from `../dragon-hunter/build/app-store/<v>/iphone-6.9/`
- painted dragons, journeys and enemies from `art/painted/`
- game icons
- the "Inkstone and Brass" palette from `ui/theme/tokens.gd`

A `sharp`-based sync script copies and web-optimises these assets into the repo. Pages stay static
Next.js server components. Two small client components add the screenshot lightbox and the store buttons' hover and tap reveal. Store
buttons are driven by two URLs in `components/site.ts` and are ported from the portfolio site's
code-built store button: dimmed with a "Coming soon" reveal while a URL is empty, a live link once
it is set. Favicons, the manifest, Open Graph and Twitter images, per-page
metadata and VideoGame JSON-LD come from Next's file conventions and are generated at build time.

## Technical Context

**Language/Version**: TypeScript 5, Node 20+

**Primary Dependencies**: Next.js 16.3.5 (App Router), React 19.2, Tailwind CSS 4, `next/font`
(Spectral, Source Sans 3), `next/og` (`ImageResponse`). New devDependency: `sharp`, used only by the
asset sync script.

**Storage**: Files only. The processed images are committed under `public/media/`, and
`components/media.generated.ts` holds their dimensions.

**Testing**: The `npm run lint` + `npm run build` gate, Lighthouse via `npx`, curl/grep checks on
the served HTML, and the manual matrix in [quickstart.md](quickstart.md).

**Target Platform**: Modern evergreen browsers, mobile first. The site is served by `next start` on
127.0.0.1:3200 behind a reverse proxy.

**Project Type**: Static marketing website.

**Performance Goals**: LCP < 2.5 s on mobile 4G, CLS ≈ 0, Lighthouse mobile performance ≥ 90 and
a11y/BP/SEO = 100. The home page should weigh under about 1.5 MB on first load, with images lazy
below the fold.

**Constraints**:
- Every page is statically rendered.
- No analytics, cookies or third-party requests (fonts are self-hosted by `next/font`).
- Content works without JS.
- Every colour comes from the game palette.
- Copy names no other game, publisher or their terms.

**Scale/Scope**: 3 pages plus a 404 and generated metadata routes. About 5 screenshots, 8 dragon
images, about 12 world images and about 6 icons.

**Structure Decision**: Keep the existing single Next.js app layout. Add the home page sections
under `components/sections/`, the hand-written content in `components/content.ts`, and the asset
pipeline as one script in `scripts/`. No tests directory: verification follows `quickstart.md`.
